## Judgment

The route into the 90s is not broader shell access. It is a sequence of evidence-bearing gates that closes the weak facets in the [[Fabric Habitat Seven-Facet Assessment|79/100 baseline]] while keeping Fabric generative and the Habitat deterministic. The target facet profile yields **92.06/100**; it is a promotion target, not a current mark.

## W1-W5 practice ring

Every cycle runs five independent source lanes in parallel and pairs them with a lane-specific Fabric dry-run:

| Workspace | Source door | Fabric adviser | Responsibility |
|---|---|---|---|
| W1 | Nushell | `extract_recommendations` | ground and reduce |
| W2 | Bacon | `analyze_logs` | inspect build evidence |
| W3 | Lazygit | `summarize_git_changes` | expose review evidence |
| W4 | Bottom | `analyze_logs` | observe runtime shape |
| W5 | JQP | `analyze_claims` | normalize and challenge claims |

The lanes then close W5 → W1 → W5. Each lane must pass source semantics, Fabric assembly, invocation policy and provenance, giving 20 dimensional checks per cycle. Fabric uses `--dry-run`, no provider/model, no session, no server mode, the standard strategy, an Arena-owned context capsule and an empty effect set.

## Promotion gates

1. Component and input provenance.
2. At least 3,600 wall-clock seconds of practice, targeting 120 cycles, 600 lane attempts and 2,400 dimensional checks at ≥95%.
3. At least 25 adversarial cases plus mutation evidence that safety gates bear weight.
4. One model-produced, non-mutating typed proposal after the user selects a provider.
5. Human-visible W3 review; missing approval means HOLD.
6. Typed operation, cold W4 rehearsal and rollback evidence.
7. Obsidian → MemPalace → W1 retrieval with source provenance.
